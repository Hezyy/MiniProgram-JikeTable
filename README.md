# 即课课表

以「课表查询 + 日程计划」为核心的微信小程序。原生框架、TypeScript、Less，数据全部保存在本机，无登录、无后端、无统计 SDK。

开发依据见 [`AGENT_DEVELOPMENT_GUIDE.md`](./AGENT_DEVELOPMENT_GUIDE.md)，本文档只描述**如何运行、验证与发布**。

## 技术栈

| 项        | 说明                                                     |
| -------- | ------------------------------------------------------ |
| 框架       | 微信小程序原生框架（`glass-easel` 组件框架）                           |
| 语言       | TypeScript（`strict`，业务逻辑不回落 JavaScript）                 |
| 样式       | Less（由微信开发者工具内置编译插件处理，`styles/variables.less` 为公共引用文件） |
| 最低基础库    | `2.32.3`（`project.config.json` 的 `libVersion`）          |
| 依赖       | 运行时零依赖；开发期仅 `typescript`、`less`、`@types/node`（用于类型检查、样式校验与单元测试） |
| 渲染       | Skyline 已关闭，使用 WebView 渲染以保证 `backdrop-filter` 与主题表现稳定  |

## 常用命令

```bash
npm install          # 安装开发期依赖（不影响小程序运行）
npm run typecheck    # 类型检查（tsc --noEmit）
npm test             # 编译并运行单元测试
npm run lint:less    # 用官方 less 编译器逐个校验所有 .less 文件
npm run lint:press   # 校验所有可点击元素都有按压反馈，且不存在触觉反馈调用
npm run verify       # 以上四项
npm run icons        # 重新生成 tabBar 图标与 styles/icons.less
```

`verify` 的四项各自验证一个层面：TypeScript 类型、纯函数行为、Less 语法与 `@import` 引用完整性、按压反馈覆盖率。微信开发者工具中的实际渲染效果仍需按下面的手工清单验收。

## 在微信开发者工具中打开

1. 用微信开发者工具「导入项目」，目录选择本仓库根目录（`project.config.json` 所在目录）。
2. 项目已配置 `miniprogramRoot: miniprogram/`，编译插件为 `typescript` + `less`，无需额外设置。
3. `project.config.json` 中的 `appid` 为演示用途，正式发布前请替换为自己的 AppID。

## 从教务系统导入课表

「设置 → 课程 → 从教务系统导入课表」可以在不输入账号密码的前提下，一次导入整学期课表：

1. 在浏览器打开学校教务系统的课表页面；
2. 从「节次 / 星期一」一直框选到右下角最后一格并复制（要包含表头和节次列）；
3. 回到小程序粘贴并解析，确认无误后导入。

> **用「按周次查询」页面时**：该页面只显示所选周次有课的课程，只复制一周会漏掉其它周的课。请先把周次选成「全部」再复制；如果只能逐周查询，就把多周的表一起粘贴进来，解析器会按课程去重合并。
>
> 教务系统在校内网或 WebVPN 后面也不影响导入——复制发生在你自己的浏览器里，小程序不参与取数。

解析全部在本机完成，**不发起任何网络请求，不需要账号密码，数据不会离开设备**。

> 为什么不直接登录教务系统代抓课表：本项目的说明与取舍记录在 `AGENT_DEVELOPMENT_GUIDE.md` 第 19.4 节。简单说，微信小程序只能请求自己在公众平台配置过的服务器域名，无法直连学校域名；统一身份认证的多跳重定向、验证码与密码加密也让这条路径在真机上不可靠；此外福建理工大学教务处 2025-05-26《关于规范教学信息查询渠道的通知》已明确对第三方课表小程序作出风险提示。

导入后请留意：

- 连堂（合并单元格）的课程序号已按相邻节次自动合并，页面会提示你核对；
- 原文没有标注周次的课程会按全部周次导入，页面会汇总提示；
- 无法识别的单元格会连同原文一起列出来，方便排查。

## 数据与隐私

- 所有数据保存在 `wx.setStorageSync`，主键 `timetable_app_data_v1`。
- 不上传任何数据，不申请位置、通讯录等权限，不接入统计 SDK。
- 数据损坏时原始内容会备份到 `timetable_app_data_v1_backup`，可在「设置 → 数据」中导出诊断或删除备份。
- 导入内容一律视为不可信数据：先解析、校验、预览统计，再由用户确认覆盖。
